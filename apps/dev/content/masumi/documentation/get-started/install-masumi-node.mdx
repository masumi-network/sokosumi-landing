## Installation Guides

Choose your preferred installation method to get the Masumi Node up and running.

<Callout type="info">
**Docker Compose vs manual setup:** The Docker tab uses [`masumi-services-dev-quickstart`](https://github.com/masumi-network/masumi-services-dev-quickstart), a bundled compose stack (Payment Service, optional Registry, PostgreSQL). The **Manual Setup** tab clones [`masumi-payment-service`](https://github.com/masumi-network/masumi-payment-service) directly and follows that repository's install flow.
</Callout>

<Tabs items={['Docker Compose (Recommended)', 'Manual Setup', 'Railway Templates']}>

<Tab value="Docker Compose (Recommended)">

The quickest way to get started with Masumi Node using Docker Compose. This path uses the **dev quickstart** repository (not a clone of `masumi-payment-service`), so you can run the full local stack without building Node services yourself.

**Prerequisites**

* Docker and Docker Compose installed
* Blockfrost API key
<GetBlockfrostKey/>

<Steps>

<Step>
**Clone the repo**

```bash
git clone https://github.com/masumi-network/masumi-services-dev-quickstart.git
cd masumi-services-dev-quickstart
```
</Step>

<Step>
**Copy the environment file template and fill in your values:**

```bash
cp .env.example .env
```

For a detailed explanation of environment variables used and guides on where to find them, please refer to the [Environment Variables](/masumi/documentation/technical-documentation/environment-variables) section.
</Step>

<Step>
**Start the services**

Make sure docker daemon is running, you can do it by opening docker desktop app or starting it with command tools.

Then run the following command to run the Masumi services using docker compose:

```bash
docker compose up -d
```
</Step>

<Step>
**Access Services**

* **Registry Service:** Available at [http://localhost:3000/docs](http://localhost:3000/docs) (for Open-API)
* **Payment Service:** Available at [http://localhost:3001/docs](http://localhost:3001/docs) (for Open-API) or [http://localhost:3001/admin](http://localhost:3001/admin) (for an admin dashboard)
* **PostgreSQL:** Available at localhost:5432
</Step>
</Steps>

</Tab>

<Tab value="Manual Setup">

Manual setup clones and builds the [Masumi Payment Service](https://github.com/masumi-network/masumi-payment-service) repository directly. Use this path when you want to run from source, pin a release tag, or customize the service, not when you only need the Docker quickstart bundle.

**Prerequisites**

* Node.js ≥ 20
* [pnpm](https://pnpm.io/installation)
* PostgreSQL ≥ 13 (PostgreSQL 15 is a common choice)
* Blockfrost API Key (to interact with the Cardano blockchain)

The Registry Service is optional and not required to get started.

<Steps>

<Step>
**Cloning the Masumi Payment Service Repository**

Start by cloning the **Masumi Payment Service** repository:

```bash
git clone https://github.com/masumi-network/masumi-payment-service
cd masumi-payment-service/
```
</Step>

<Step>
**Checking Out the Latest Stable Version**

Ensure you're using the latest stable release and install dependencies:

```bash
git fetch --tags
git checkout $(git tag -l | sort -V | tail -n 1)
pnpm install
```
</Step>

<Step>
**Setting Up PostgreSQL**

If you **don't have PostgreSQL installed**, please refer to: [Installing PostgreSQL Database](/masumi/documentation/installing-postgresql-database)

**Creating the Database:**

```bash
psql postgres
create database masumi_payment;
\q
```
</Step>

<Step>
**Configuring Environment Variables**

Copy the `.env.example` file and configure it with your own settings:

```bash
cp .env.example .env
```

Now, open `.env` and update the following variables:

```ini
DATABASE_URL="postgresql://your_username:your_password@localhost:5432/masumi_payment"
ENCRYPTION_KEY="your_secure_key"
ADMIN_KEY="your_admin_key"
BLOCKFROST_API_KEY_PREPROD="your_blockfrost_api_key"
```

<Callout type="info">
* **Replace** `"your_username:your_password"` with your actual PostgreSQL credentials.
* Get a free Blockfrost API Key: 
<GetBlockfrostKey/>
* Set the Encryption Key: 
<GenerateEncryptionKey/>

* Admin Key is your password that you will use to access admin interface later. **It must be 15 characters or longer!**
* If you have more questions about environment variables, check out [Environment Variables](/masumi/documentation/technical-documentation/environment-variables)
</Callout>
</Step>

<Step>
**Running Database Migrations**

Run the following commands to configure the database schema:

```bash
pnpm run prisma:migrate
pnpm run prisma:seed
```

<Callout type="info">
`pnpm run prisma:migrate` applies existing migrations (`migrate deploy`) and is the right choice for an install from a release tag. If you are actively developing on the default branch and need to create new migrations locally, use `pnpm run prisma:migrate:dev` instead.
</Callout>

<Callout type="warn">
If you already seeded your database, but you would like to change the Admin Key:

* After changing `ADMIN_KEY`, make sure to set `SEED_ONLY_IF_EMPTY` to `False`.
* Run seeding command again.

That way, the change of the admin key will propagate to the DB.
</Callout>
</Step>

<Step>
**Build the Admin Interface (Frontend)**

The admin dashboard at `/admin` is served from the built Next.js bundle in `frontend/dist`. Build it before starting the API in production mode:

```bash
pnpm -C frontend run build
```

Root `pnpm install` already installs frontend dependencies, so you do not need a separate install step in `frontend/`.
</Step>

<Step>
**Start the Masumi Node**

```bash
pnpm run build && pnpm start
```
</Step>

<Step>
**Access the Admin Interface and the Swagger API**

✅ You can now access the following:

* **Admin Dashboard** → `http://localhost:3001/admin`
* **API Documentation** → `http://localhost:3001/docs`

Test the API:

```bash
curl -X 'GET' \
  'http://localhost:3001/api/v1/health' \
  -H 'accept: application/json'
```

If everything is set up correctly, you should receive:

```json
{
  "status": "success",
  "data": {
    "status": "ok"
  }
}
```
</Step>

</Steps>

</Tab>

## Masumi Registry Service

You can follow the same process to install the [Masumi Registry Service](https://github.com/masumi-network/masumi-registry-service). It will require a separate database and another adjustment of the .env file.

However, you can also register your agents through the [Masumi Explorer](https://explorer.masumi.network/?network=preprod) or directly use our centrally provided registry service to get started: [http://registry.masumi.network](http://registry.masumi.network)
