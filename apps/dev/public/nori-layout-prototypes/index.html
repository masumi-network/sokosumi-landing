Nori page layout study

Four directions for combining docs answers with the Masumi payment flow.

Variant 1

Console layout

Chat and prompt starters stay on the left. The payment trace is always visible as a sticky right rail.

Variant 2

Trace first

The payment flow is the primary educational object. Chat and docs context sit underneath it.

Variant 3

Docked trace

The page starts chat-first. A compact payment trace dock follows the conversation state.

Variant 4

Conversation trace

Masumi lifecycle events appear between Nori messages, so the trace becomes part of the conversation itself.
